# Vision Preox International — website

Static website for Vision Preox International (visionpreox.co.ke).

Files:
- `index.html` — the whole site (HTML, CSS and JavaScript in one file)
- `logo-badge.png`, `logo-full.png` — logo images
- `favicon-64.png`, `apple-touch-icon.png` — browser and phone icons

No build step is needed. Any static host (Cloudflare Pages, GitHub Pages, Netlify) can serve this folder as it is.
To edit text, open `index.html`, change the words, and commit — Cloudflare Pages redeploys automatically.
